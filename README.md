# Final Year Project: Cybersecurity on Power System

This project analyzes the impact of cyberattacks on power system stability and control, focusing on **False Data Injection Attacks (FDIA)**, **Delay Attacks**, and **Replay Attacks**.

## Files

- **5bus_dynamic_response.m** — Simulates the dynamic response of a 5-bus power system.
- **diff_attack_on_system.m** — Models and analyzes the effect of different cyberattacks (FDIA, Delay, Replay,noise,dos,packet drop attack) on the power system.
- **two_area_lfc.m** — Implements a two-area Load Frequency Control (LFC) model to study frequency stability under attack scenarios.

## How to Run

1. Open MATLAB.
2. Clone or download this repository.
3. Open the desired `.m` file in MATLAB.
4. Run the script to view simulation results and plots.

## Requirements

- MATLAB (R2020a or later recommended)
- Simulink (if applicable)

## Project Description

The project investigates how various cyberattacks compromise power system control loops and proposes/evaluates system behavior under such attacks to understand vulnerabilities in power grid infrastructure.
